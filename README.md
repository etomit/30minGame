# 30minGame

Un petit jeu d'arcade en HTML et JavaScript : pilote un avion, esquive les projectiles et bats ton score.

Ouvre `index.html` dans un navigateur pour jouer. Aucune installation ni compilation n'est requise.

- Fleches haut et bas : deplacer l'avion.
- Une balle esquivee rapporte 100 points.
- La vitesse des balles augmente progressivement avec le score.
- Bouton Redemarrer ou Espace apres une defaite : nouvelle partie.
- La partie se met en pause en quittant la fenetre ou l'onglet, puis reprend au retour.

Le ciel et la ville defilent a des vitesses differentes pour creer un effet de parallaxe.
Les reglages se trouvent au debut de `jeu.js`. Les prompts des images generees sont conserves dans `ASSETS.md`.
