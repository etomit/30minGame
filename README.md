# 30minGame

Un petit jeu d'arcade : pilote un avion et esquive les balles.

Ouvre `index.html` dans ton navigateur. Fleches haut/bas pour bouger, bouton Redemarrer ou Espace apres une defaite pour recommencer. La partie se met en pause quand tu quittes la fenetre.

Reglages : `jeu.js` pour le jeu, `fond.js` pour le decor et la parallaxe.
